开始训练

教程框架与训练方法

本教程把 StarCraft 训练组织成可选择、可执行、可复盘的训练闭环。它不是按章节顺序读完的百科，也不依赖 Replay 或 AI 才能使用。

五类稳定资产

训练方向入口

训练方向负责解释能力边界、能力地图和推荐起点。

训练方向页是导航，不承担完整训练正文，也不创建评分规则。

训练主题

训练主题围绕一项主要能力组织：

  • 为什么重要
  • 如何判断
  • 常见失败模式
  • 如何练习
  • 何时算完成

它是实际学习、练习和完成的核心单元。

训练卡

训练卡把一个主题压缩成单局动作：

  • 一个主要行为变化
  • 一个或少量明确触发器
  • 可观察的判断规则
  • 单局和多局完成标准

一局只携带一张训练卡。

场景包

场景包负责地图、模式、种族或团队语境适配。

BGH 场景包可以调整触发器、观察对象和协同条件，但不能重新定义训练方向。

出版时，BGH 适配分别放在对应训练方向末尾；地图、点位和临时角色等共享内容放入参考附录。

训练路径

训练路径根据用户目标组织主题顺序：

  • 新手：先建立执行底座，再扩展完整闭环
  • 回流玩家：通过自测选择最早失败点
  • BGH 固定车队：按团队事件和协同约定训练

训练方向

训练方向 主要职责 推荐起点
开局与节奏建立 开局计划、执行、节奏和恢复 固定开局主线
经济与生产转化 经济、生产、人口和转化 持续补充工人

后续六个部分会分别展开各训练方向的边界、判断模型和训练顺序。

人工训练闭环

选择用户路径
  -> 进入一个训练主题
  -> 阅读判断模型
  -> 选择一张训练卡
  -> 单局执行
  -> 连续三局人工复盘
  -> 继续、降级或切换主题

统一执行规则见人工训练与复盘方法。

核心约束：

  1. 一次只训练一个主题
  2. 一局只携带一张训练卡
  3. 先记录事实，再解释原因
  4. 连续三局后再判断是否切换
  5. 胜负不是单张训练卡的唯一完成标准

如何开始

按当前身份选择：

  • 新手基础训练路径
  • 回流玩家恢复路径
  • BGH 固定车队训练路径

如果无法判断自己的类型，从新手路径开始；已经能稳定完成基础动作，则使用回流路径的六项自测。

训练结果怎么判断

训练结果只回答本主题是否改善：

  • 是否识别触发器
  • 是否执行训练动作
  • 是否避免主要错误
  • 是否达到单局和多局标准

不使用单局胜负直接证明能力提升，也不把无法观察的原因写成确定结论。

第一部分 开局与节奏建立

开局与节奏建立

稳定开局不是背下完整流程，而是明确主线、按时完成关键节点，并在出现偏差后保住下一步。

本章要解决的问题

开局阶段资源有限、动作密集，任何遗漏都会影响后续生产和第一轮行动。本章回答：

如何把一套开局从记忆内容变成可以稳定执行和恢复的行动主线？

答案是按顺序完成四件事：

选择一套主线
  -> 写下五个关键节点
  -> 对照种族模板执行目标时间
  -> 连接第一次有效行动

开局判断模型

顺序 需要保证的事情 判断问题
第一层 主线清楚 能否说出五个关键节点
第二层 节点按时 建筑开工或单位完成是否接近目标时间
第三层 生产连续 工人、补给和主生产是否为赶节点而断开
第四层 行动衔接 第一批单位完成后准备侦察、施压、支援还是扩张

目标时间代表无干扰下的最佳执行状态。受到骚扰或主动变体后，不再机械追赶旧时间，而是记录最早偏差并保护下一个关键节点。

训练顺序

  1. 先用固定开局主线写出五个节点
  2. 再选择对应种族和用途的模板
  3. 单局只检查最早出现的节点偏差
  4. 连续执行稳定后，再训练受压恢复和主动变体

本章边界

本章负责前几分钟的计划、节点、生产连续性和第一次行动。整局经济规模由经济与生产转化处理，中后期威胁和止损由局势响应、支援与风险控制处理。

第一层：固定开局主线

本层结论

连续执行一条足够短的开局主线，在被小干扰或临时分心时也能回到下一项关键动作。

在链条中的位置

稳定开局不是背完整 Build Order，而是让前几分钟的资源、补给、生产和首个战略动作彼此衔接。主线频繁改变会同时拖慢经济、兵力、侦察和团队到场时间。

如何判断

把开局压缩成五个关键节点：

  1. 第一轮工人和资源分配
  2. 第一个补给节点
  3. 第一组生产设施
  4. 第一次侦察
  5. 第一个战略动作：出门、扩张或科技

每完成一个节点，只确认下一节点，不在局中重新设计整套开局。

选择具体模板后，每个节点还要记录：

  • 供给与动作顺序
  • 建筑开始或完成的目标时间
  • 单位开始生产或完成的目标时间
  • 第一批单位的行动任务

目标时间表示无干扰时的最佳执行状态。每局记录实际时间和偏差，但不能通过长期停工人、漏补人口或中断主要生产来换取单个节点准时。

怎么做

  1. 从各族开局模板选择一个当前常用开局
  2. 写下五个关键节点和对应目标时间
  3. 连续三局使用同一主线
  4. 每次偏离时记录“在哪个节点断开、延误多久”
  5. 下一局只修最早出现的断点

常见失败

  • 同一套开局连续几局使用不同顺序
  • 因为侦察或小规模骚扰忘记下一关键节点
  • 为追求细节记忆，反而漏掉工人、补给或生产
  • 只看最终建筑时间，没有找到最早延误的节点
  • 为赶秒表停工人或断生产，表面准时但后续节奏失效
  • 失败后立刻更换开局，无法判断问题来自方案还是执行

达标标准

单局达标

  • 五个关键节点没有漏掉两个以上
  • 主要节点以目标时间为执行方向，并记录实际偏差或主动变体原因
  • 没有为赶时间长期停工人、卡人口或中断主要生产
  • 出现干扰后能在下一个节点回到主线
  • 没有在局中无依据地切换完整开局

多局完成

连续三局中至少两局达到单局标准，并能准确说出仍不稳定的一个节点。

本局训练卡：五节点开局检查

使用条件

  • 开局经常漏掉关键建筑、补给、生产或侦察
  • 被轻微干扰后无法回到原计划
  • 每局都在临时更换开局

局前先从各族开局模板选择一套模板。

本局只改什么

局前写下并记住五个关键节点及其目标时间；本局按顺序执行，并记录第一个时间偏差或顺序断点。

触发时机

  • 每完成一个关键节点
  • 被侦察、骚扰或临时操作打断后

观察对象

  • 当前完成到第几个节点
  • 下一节点需要的资源和操作
  • 关键建筑或单位相对目标时间提前或延误多少
  • 工人、人口和主要生产是否保持连续
  • 干扰后是否仍知道恢复位置

判断规则

  • 节点正常：继续下一节点
  • 节点晚于目标但仍可执行：记录延误，优先补回该节点
  • 局势已经使原节点失效：明确跳过原因，再进入下一有效节点

常见错误

  • 试图记住完整细节而忘记主线
  • 为赶秒表停止工人或主要生产
  • 只记录最终建筑晚了，没有寻找最早断点
  • 一次漏步后彻底放弃计划
  • 没有新信息却临时更换开局

单局达标标准

  • 五个节点没有漏掉两个以上
  • 主要节点以目标时间为执行方向，并记录实际偏差或主动变体原因
  • 没有为赶时间长期停工人、卡人口或断主要生产
  • 干扰后至少一次成功回到主线

多局完成标准

连续三局中至少两局达标，并能说清最常见的一个断点。

局后复盘

  1. 第一个断点是什么，早了或晚了多久
  2. 延误来自资源、人口、生产、注意力还是主动变体
  3. 当时是否仍在持续生产工人和主要单位
  4. 下一局要保留哪个恢复动作

地图适配：BGH

本层变化

BGH 的第五个开局节点必须连接团队第一次共同动作。个人主线仍保持五个节点，但最后一步要写明抢中、支援、扩张或科技，不能只写个人发展目标。

场景动作

  1. 开局前确认出生位和临时角色
  2. 写下个人前四个生产节点
  3. 将第五节点写成个人单位与团队行动的连接点
  4. 侦察发现异常时说明谁调整、谁保留原计划

失败信号

  • 只背个人顺序，没有队友到场节点
  • 为了同步出门跳过补给或主要生产
  • 团队临时改目标后，个人整套开局全部重做

场景复盘

  • 第一批单位完成后是否有团队任务
  • 第一次共同动作是否与个人目标时间衔接
  • 主动变体是否由新信息触发

第二层：选择并执行种族模板

开局模板把固定开局主线落实为具体的建筑、单位和转型节点。模板用于练习稳定执行，不代表任何对局都必须照表完成。不熟悉的单位、建筑和战术简称可查星际专业名词解释。

选择自己的种族：

  • Protoss 开局模板
  • Terran 开局模板
  • Zerg 开局模板

使用前提

每次只选择一套模板，并在局前说清：

  1. 这套开局要解决什么问题
  2. 前五个关键节点是什么
  3. 第一批单位完成后准备做什么
  4. 哪些信息出现时需要变体或停止原计划

如果无法回答，不要先背完整秒表，先回到五节点训练。

目标时间怎么使用

模板中的时间表示无干扰、工人和主要生产连续时的最佳执行目标。它是一个明确时间点，不是宽泛区间。

当前目标值由旧版秒表整理而来，作为训练方向使用；是否精确以及不同版本、地图和位置是否需要修正，留待后续受控实战或 Replay 样本校准。在完成校准前，不设置“允许误差几秒”的正式达标线。

记录节点时应区分：

  • 建筑开始建造
  • 建筑完成
  • 单位开始生产
  • 单位完成
  • 第一批部队具备行动条件

每局记录：

目标时间 -> 实际时间 -> 提前或延误 -> 最早断点

目标时间默认假设开局未受明显干扰，并持续生产工人。地图位置、采矿效率、操作延迟和对手干扰都可能造成偏差。

达标规则

一套开局同时满足以下条件才算达标：

  1. 关键节点按正确顺序完成
  2. 主要节点以目标时间为最佳执行方向，并记录实际偏差
  3. 没有为了赶时间长期停工人
  4. 没有因为漏补人口打断主要生产
  5. 第一批单位完成后有明确任务

不能通过牺牲后续经济和生产来换取一个节点准时。

偏离后怎么判断

出现延误时，先找最早断点：

  • 资源不足：检查工人生产和资源分配
  • 人口不足：检查补给是否提前开始
  • 建筑延误：检查前一个节点是否过晚或资源被挪用
  • 单位延误：检查生产建筑、人口和持续生产
  • 主动变体：记录触发信息，不算无理由漏步

受到明显骚扰或侦察发现必须变化后，不再要求后续节点严格匹配原目标时间。此时改为检查：

  1. 是否能说清改变原因
  2. 是否优先完成生存和团队职责
  3. 是否为新的下一节点给出时间目标

训练方法

  1. 从种族页面选择一套适合当前角色的模板
  2. 抄下供给顺序和五个目标时间点
  3. 连续三局使用同一模板
  4. 每局只记录第一个出现时间偏差或顺序错误的节点
  5. 下一局只修这个最早断点

连续三局中至少两局达到模板标准后，再练习对手与位置变体。

BGH 团队局完成开局模板后，使用中期转型方案选择第一轮中期方向。

第二部分 经济与生产转化

经济与生产转化

稳定经济不是资源越多越好，而是持续采集，并及时转化为人口空间、生产能力和有效兵力。

本章要解决的问题

正常情况下，资源应沿着“采集、容纳、生产、转化”的链条形成战力。但侦察、移动和战斗会不断夺走注意力，使链条在某个位置断开。

本章只回答一个问题：

如何在注意力频繁转移时，仍让经济稳定形成下一轮有效兵力？

答案是按固定顺序检查四层：

持续补工
  -> 提前准备人口
  -> 保持主生产运转
  -> 为剩余资源选择明确出口

四层判断模型

顺序 需要保证的事情 先问什么 本局动作
第一层 持续补充工人 是否因为注意力遗漏而停工 基地切回先看工人
第二层 提前准备人口 下一轮生产是否会撞上人口上限 出门前检查补给
第三层 保持主生产运转 有资源和人口时主生产是否空转 移动或战后补一轮
第四层 及时转化资源 剩余资源准备形成什么收益 资源积累先选一个出口

这四层不是四个并列技巧，而是一条因果链：

  • 工人断档，后续收入不足
  • 人口不足，收入无法进入生产
  • 生产空转，资源无法形成单位
  • 没有明确出口，额外收入只会长期堆积

训练顺序

从最早断开的层开始训练，不要一局同时修四层。

  1. 经常无理由停工：先练持续补工
  2. 工人稳定但经常卡人口：再练补给节奏
  3. 资源和人口都够但设施空转：再练主生产
  4. 主生产稳定后仍长期积累资源：最后练资源转化

前一层没有稳定时，不用靠增加更多产能、扩张或复杂科技掩盖问题。

本章边界

本章负责让资源稳定形成可用产出，不负责：

  • 前几分钟的具体 BO 是否按目标时间完成，由开局与节奏建立处理
  • 战斗中单位是否打出有效交换，由战斗控制与交换质量处理

接下来按四层顺序学习。每一层都包含原理、本局训练卡和对应地图适配。

第一层：持续补充工人

本层结论

没有明确停工理由时，基地应持续补充工人；必须停工时，也要同时确定恢复生产的节点。

在链条中的位置

工人决定后续每一轮生产、科技和扩张的资源基础。无计划停工造成的损失会持续累积，不能靠后期一次补很多工人完全追回。

训练重点不是无条件贪工人，而是区分两类情况：

  • 主动停工：为了立即补兵、保命或完成关键转型
  • 注意力遗漏：看前线、侦察或扩张后忘记继续生产

本层只修正第二类。

如何判断

每次切回基地时依次问：

  1. 基地是否正在生产工人
  2. 当前是否存在必须立刻停工的具体原因
  3. 如果必须停工，准备在什么事件后恢复

无法说清原因和恢复节点，就视为注意力遗漏。

怎么做

先建立一个触发器：

主力获得长距离移动命令
  -> 切回基地
  -> 检查工人生产
  -> 再处理其他运营

触发器稳定后，再加入“交战结束”和“新基地完成”。

常见失败

  • 一看前线就长时间不再检查基地
  • 新基地完成后没有纳入补工循环
  • 为了赶科技或兵力停工，却没有恢复节点
  • 只看最终工人数，不找第一次无理由停工

达标标准

  • 第一次出门和第一次交战后都检查过工人生产
  • 没有无法解释的长时间停工
  • 连续三局中至少两局达标，并能说清一次合理停工的原因

本局训练卡：基地切回先看工人

使用条件

  • 一看前线就容易停止补工
  • 新基地完成后经常忘记生产工人

本局只改什么

每次主力获得新的移动命令后，切回基地检查一次工人生产。

触发时机

  • 主力开始长距离移动
  • 一波交战结束
  • 新基地完成

观察对象

  • 基地是否正在生产工人
  • 当前是否有明确停工理由
  • 下一次恢复生产的节点

判断规则

  • 没有停工理由：立即补工
  • 必须保命：允许暂时停工，并记录恢复节点
  • 新基地已运转：把它纳入相同检查

常见错误

  • 为完成训练而在危险时无条件补工
  • 只看最终工人数，不记录第一次停工
  • 切回基地后处理过多操作，错过前线

单局达标标准

  • 第一次出门和第一次交战后都执行检查
  • 没有无法解释的长时间停工

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 第一次停工发生在什么时候
  2. 是主动决策还是注意力遗漏
  3. 下一局保留哪个触发器

地图适配：BGH

边位受压时可以为了生存暂时停工，安全位和科技位则应避免因为观察队友交战而无计划停工。

场景触发器

  • 队伍第一次集合或转线后检查工人
  • 边位压力解除后恢复工人生产
  • 新基地开始运转后纳入补工循环

场景判断

  • 为立即补兵保命而停工：合理，但要说明恢复节点
  • 为观察中路或队友交战而停工：注意力遗漏
  • 安全位长期停工：优先修正，不用归因于团队战斗

场景复盘

  • 第一次团队事件是否造成工人生产中断
  • 哪次停工属于生存决策
  • 压力解除后是否及时恢复

第二层：提前准备人口

本层结论

补给要在注意力离开基地前准备完成，目标是容纳下一轮关键生产，而不是追求整局绝不卡人口。

在链条中的位置

工人持续提供收入后，人口空间决定这些资源能否进入生产。关键时点卡人口会同时延误工人、主战单位、出门和支援。

过早堆叠补给同样会挤压当前兵力和科技，因此正确目标是“够下一轮使用”，而不是越早越多越好。

如何判断

进入下一轮生产前依次问：

  1. 剩余人口能否容纳即将开始的工人与部队
  2. 补给能否在这些单位完成前生效
  3. 接下来是否会因为出门、交战或扩张而暂时忘记基地

第三项风险较高时，应在注意力切走前完成补给动作。

怎么做

先建立主要触发器：

主力准备出门
  -> 检查剩余人口
  -> 估算下一轮工人与部队
  -> 不够则先补给
  -> 再把注意力转向前线

稳定后再加入“交战结束”和“新增生产设施”两个触发器。

常见失败

  • 已经卡住才开始补给
  • 主力出门前只看兵力，不看人口
  • 战后只补兵，没有同步准备人口
  • 为了绝不卡人口而过早投入多个补给

达标标准

  • 主力第一次出门前完成补给检查
  • 没有因为卡人口明显打断工人或主战单位生产
  • 连续三局中至少两局达标，并且没有以过量补给换取达标

本局训练卡：出门前检查补给

使用条件

适合：

  • 经常在主力出门、交战或集中补兵时卡人口
  • 还没有稳定补给检查触发器

暂不适合：

  • 当前主要问题是资源不足，而不是人口空间不足
  • 已经稳定控制卡人口，需要进一步训练扩张或生产规模

本局只改什么

每次主力准备出门前，执行一次：

看剩余人口
  -> 估算下一轮工人和部队
  -> 不够则先补给
  -> 再把注意力转向前线

本局不要同时增加其他新训练目标。

触发时机

主要触发器：

  • 主力准备离开集结区

辅助触发器：

  • 一波交战结束，准备集中补兵
  • 新增生产建筑后，准备提高产量

基础阶段只强制使用主要触发器。连续三局能够执行后，再加入辅助触发器。

观察对象

  • 当前已用人口和人口上限
  • 下一轮工人与主战单位需要的人口
  • 补给建筑或单位完成所需时间
  • 自己是否即将把注意力切到前线

判断规则

  • 下一轮生产会撞上人口上限：先补给
  • 人口空间足够且补给会明显挤压当前关键兵力：暂不补
  • 无法精确计算：保证下一轮关键生产不被打断，不为追求零卡顿过量补给

常见错误

  • 已经卡住才开始补给
  • 出门前只检查兵力，不检查人口
  • 交战结束后连续补兵，但忘记同步补给
  • 一次造过多补给，导致当前兵力或科技延迟
  • 复盘只记“又卡人口”，没有记录卡住前的触发场景

单局达标标准

  • 主力第一次出门前执行过补给检查
  • 本局没有因为卡人口造成明显断工或断兵

多局完成标准

最近连续 3 局中至少 2 局达到单局标准，并且没有明显过早、过量补给。

未达到时不要换卡。下一轮只保留主要触发器，减少其他训练目标。

局后复盘

只回答四个问题：

  1. 第一次关键卡人口发生在什么时候
  2. 卡住前 20 秒我在做什么
  3. 主力出门前我是否执行了补给检查
  4. 下一局需要保留还是调整触发器

地图适配：BGH

BGH 的抢中、支援和战后补兵会集中夺走注意力。补给检查应绑定团队动作，避免个人卡人口拖慢整队下一轮到场。

场景触发器

  • 队伍准备第一次集体出门
  • 中路交战结束，准备集中补兵
  • 准备增加一轮生产设施

场景判断

  • 为同步出门跳过补给检查：错误
  • 接敌已经开始后长时间切回基地补给：时机过晚
  • 战后资源充足但人口不足：恢复链在补给层断开

场景复盘

  • 第一次团队出门前是否检查人口
  • 战后补兵是否再次卡住
  • 个人补给延误是否影响团队集合

第三层：保持主生产运转

本层结论

先让一条主生产线持续运转，再增加科技线、生产规模和复杂兵种。

在链条中的位置

收入和人口空间准备好以后，生产设施才是资源形成单位的通道。设施空转不仅浪费建筑投入，还会损失无法追回的生产时间。

本层不把所有停产都视为错误。先区分四种原因：

  1. 缺资源：收入与生产规模不匹配
  2. 卡人口：上一层没有准备好
  3. 忘记操作：没有稳定生产触发器
  4. 主动停产：正在转型或保存关键资源

本层直接修正第三类，其余问题回到对应层处理。

如何判断

指定本局唯一主生产线，然后检查：

  • 有资源且有人口时，它是否长时间空转
  • 新增设施后，原有生产循环是否仍能覆盖
  • 战后恢复时，下一轮主战单位是否及时接上

怎么做

使用两个触发器：

主力开始长距离移动 -> 补一轮主战单位
一波交战结束       -> 补一轮主战单位

每次只处理主生产和必要补给，不在同一次切回中完成全部科技与运营。

常见失败

  • 主力一移动就忘记生产
  • 新增生产设施后仍按旧节奏操作
  • 同时检查多条科技线，反而让主生产断档
  • 有资源时一次排满，之后继续长时间空转

达标标准

  • 第一次移动和第一次战后都补过一轮主生产
  • 没有出现有资源、有人口却无理由长时间空转
  • 连续三局中至少两局达标，并能判断第一次空转属于哪种原因

本局训练卡：移动或战后补一轮

使用条件

  • 有资源和生产设施，却经常忘记出兵
  • 战斗结束后兵力恢复明显慢于队友

本局只改什么

主力开始移动或一波战斗结束后，补一轮当前主战单位。

触发时机

  • 主力获得长距离移动命令
  • 一波交战结束

观察对象

  • 主生产设施是否空转
  • 人口和资源是否允许下一轮生产
  • 当前是否在主动转型

判断规则

  • 资源和人口足够：补一轮主战单位
  • 卡人口：先执行补给动作
  • 正在转型：记录停产原因和恢复节点

常见错误

  • 一次切回处理全部科技和运营
  • 明明缺资源却把问题归因于忘记生产
  • 交战尚未稳定就长时间离开前线

单局达标标准

  • 两个主要触发器至少各执行一次
  • 没有无理由长时间空转

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 第一次空转发生在哪个阶段
  2. 原因是资源、人口、转型还是遗忘
  3. 下一局保留哪个生产触发器

地图适配：BGH

第一集合、抢中结束和等待队友是稳定的生产空窗。支援前补一轮可以减少到场后的兵力断层，但接敌已经开始时不要长时间离开前线。

场景触发器

  • 前往第一集合点
  • 等待后排或支援单位到场
  • 中路交战结束并重新集合

场景判断

  • 集合路上有资源和人口：补一轮主战单位
  • 已经进入激烈接敌：优先保持阵型与协同
  • 战后只有资源没有续兵：检查主生产是否空转

场景复盘

  • 哪个集合或战后空窗本可以补一轮
  • 主力和续兵为何没有同时到场
  • 是否为了处理完整运营错过团队动作

第四层：及时转化资源

本层结论

主生产稳定后仍有资源积累，应为剩余资源选择一个主要出口：兵力、生产规模、科技或扩张。

在链条中的位置

高资源不一定是错误。为关键科技或扩张短时存钱属于计划；长期不知道资源要形成什么，才是转化链断开。

如果主生产仍在空转，先回到第三层。盲目增加建筑只会放大已有问题。

如何判断

资源明显积累时依次问：

  1. 主生产是否持续运转
  2. 是否正在为一个明确目标存钱
  3. 现有产能能否消化当前收入
  4. 当前局势是否允许扩张或科技

没有明确计划时，只选择一个主要出口：

当前状态 优先出口
主战单位不足 继续兵力生产
收入持续超过现有产能 增加可持续使用的生产设施
兵力能够维持当前安全 推进一个关键科技
路线可守且资源能够利用 建立扩张

怎么做

建立一个资源提醒。触发后先说清“这笔资源要形成什么”，再执行一个动作。下一次检查时确认该出口是否真的开始产生收益。

常见失败

  • 把所有高资源状态都视为错误
  • 同时选择扩张、科技和大量产能
  • 为花钱建立无法持续运转的生产设施
  • 扩张后没有同步计划如何使用新增收入

达标标准

  • 至少一次资源提醒后说清并执行一个主要出口
  • 没有长时间无计划堆积
  • 没有为了花钱建立无法运转的产能
  • 连续三局中至少两局达标，并能区分合理存钱与无计划积累

本局训练卡：资源积累先选一个出口

使用条件

  • 经常资源很多但兵力、科技和扩张都没有推进
  • 会一次补很多建筑，却无法持续生产

本局只改什么

资源明显积累时，立即选择兵力、生产规模、科技或扩张中的一个主要出口。

触发时机

  • 资源连续增加但主生产已经排满
  • 一波交战结束并进入运营空窗

观察对象

  • 是否正在为明确目标存钱
  • 主生产能否消化当前收入
  • 当前最缺的是兵力、产能、科技还是基地

判断规则

  • 有明确存钱目标：继续，并保留必要兵力
  • 主生产空转：先恢复生产
  • 收入超过产能：增加可持续使用的生产
  • 局势安全且收益明确：考虑扩张或科技

常见错误

  • 资源一多就无条件扩张
  • 同时选择多个出口
  • 只建产能但后续没有资源使用

单局达标标准

  • 至少一次触发后说清并执行一个主要出口
  • 没有长时间无计划堆积

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 第一次资源积累时是否有计划
  2. 最终选择了哪个出口
  3. 这个选择是否真正转成有效收益

地图适配：BGH

中路和安全空间只有转成可持续生产、关键科技、扩张或下一轮团队兵力才形成经济收益。

中路收益

控制中路后至少选择一个出口：

  • 建立可防守的中矿或扩张
  • 增加能够持续运转的生产规模
  • 完成能改变下一轮交战的关键科技
  • 加快战后兵力恢复

只停留在中路而没有资源、视野或行动收益，不算完成转化。

扩张判断

准备占用资源点时检查：

  1. 队伍是否仍有足够自保兵力
  2. 新基地是否位于可支援路线内
  3. 新增收入准备形成什么产能或科技
  4. 对手反击时由谁先守、谁负责补位

扩张不能同时依赖“对手不会来”和“队友一定能救”两个未经确认的假设。

场景复盘

  • 中路或扩张资源最终转化成了什么
  • 是否同时选择过多出口
  • 新资源点是否处于可支援范围

具体训练：常见经济断点

经济训练不是追求资源数字越高越好，而是在注意力受干扰时保持“工人、人口、生产、资源出口”这条转化链。

怎么组织对练

使用同一套熟悉开局，连续三轮只制造一种干扰：

  1. 第一轮无敌人压力，确认正常基线
  2. 第二轮在固定时间加入移动、侦察或短交战
  3. 第三轮重复同一干扰，检查最早断点是否后移或消失

每轮只修最早断点。后面的资源积累如果由前面的停工或卡人口造成，不同时增加第二张训练卡。

侦察操作导致工人停产

  • 在侦察单位出发前补上当前工人
  • 侦察操作结束后第一次切回基地先检查工人队列
  • 不为控制侦察单位长时间停留在敌方基地
  • 记录第一次空队列发生在出发、观察还是撤离
  • 工人恢复连续后，再增加更复杂的侦察路线

出门时发生人口阻塞

  • 在主力集合前检查当前人口和下一轮生产需求
  • 提前开始补给，不等生产建筑全部亮红
  • 出门命令完成后再次确认补给是否已经在建
  • 卡人口时先记录最早漏检节点，不用连续补多个补给掩盖问题
  • 连续三轮不因第一次出门卡住主生产后，再增加多线移动

控兵期间主生产空转

  • 给主力下达安全移动命令后补一轮主战单位
  • 激烈交战期间保留前线操作，不强行完成整套运营
  • 交战结束后先恢复人口和主生产，再处理次要科技
  • 记录空转开始时间以及当时占用注意力的动作
  • 生产恢复稳定后，再增加第二条生产线或科技线

战后资源快速积累

  • 战斗结束后先判断人口、主生产和工人是否连续
  • 为剩余资源只选择一个出口：扩产、科技、扩张或补充关键单位
  • 出口必须服务于下一阶段计划，不因看到高资源同时增加所有项目
  • 下一次接敌前检查新增投入是否已经形成产能或兵力
  • 无法说明资源用途时，回到最早未完成的生产环节

防守压力下被迫暂停经济

  • 区分主动停工与注意力遗漏，并记录停止原因
  • 先完成生存所需的最低投入，不机械维持和平状态下的目标时间
  • 压力解除后按工人、人口、主生产、资源出口顺序恢复
  • 不在危险仍存在时一次补回全部经济缺口
  • 能说明何时停止、何时恢复，才算完成这一轮训练

综合决策与训练计划

找到最早断点

复盘时不要同时统计所有经济失误。沿着生产链找到最早发生、并影响后续动作的断点：

工人是否无理由停产？
├─ 是：训练持续补工
└─ 否：下一轮生产是否被人口卡住？
   ├─ 是：训练提前准备人口
   └─ 否：主生产是否在资源充足时空转？
      ├─ 是：训练保持主生产运转
      └─ 否：剩余资源是否没有明确出口？
         ├─ 是：训练及时转化资源
         └─ 否：本章训练暂时达标

如果后面的现象由前面的断点引起，只记录最早断点。例如，卡人口导致生产空转时，本局先训练补给，不同时训练生产循环。

三局训练计划

第一局：只确认断点

  • 按四层顺序观察
  • 记录最早失败发生的时间和场景
  • 不要求在当局同时修正全部问题

第二局：只携带一张训练卡

  • 选择最早断点对应的训练卡
  • 全局只强制执行一个主要触发器
  • 局后记录是否执行，而不是只看输赢

第三局：重复同一张卡

  • 不因上一局失败立即换题
  • 检查同一触发器能否再次执行
  • 连续三局中至少两局达标后，再进入下一层

进行具体断点训练时，三局保持同一开局和干扰类型；最早断点稳定后，每轮只增加一个新的注意力压力。

本章完成标准

完成本章不要求经济操作完美，而要求玩家能够：

  1. 按工人、人口、生产、资源出口的顺序定位问题
  2. 区分主动停产、合理存钱和注意力遗漏
  3. 为最早断点选择一张对应训练卡
  4. 连续三局中至少两局执行主要触发器
  5. 说明地图或团队条件如何改变触发时机，而不是改变经济原则

下一步

四层都能稳定执行后，再训练扩张时机、基地饱和度、科技推进和兵种结构。这些内容建立在经济链已经能够持续运转的基础上。

SECTION

第三部分 信息获取与判断

信息获取与判断

有效侦察不是看见更多，而是在需要决策前获得足够信息，并把观察转成下一步行动。

本章要解决的问题

对手信息会不断过期。首侦只能建立初始判断，后续生产、移动和战斗又会持续占用注意力。本章回答：

如何持续发现关键变化，并避免用过期信息做决定？

答案是建立三层信息循环：

按时完成首侦
  -> 在决策前刷新信息
  -> 用小地图维持持续感知

三层判断模型

顺序 需要保证的事情 判断问题 本局动作
第一层 建立初始事实 首侦是否在仍可调整时到达 首侦三步闭环
第二层 更新旧判断 下一次关键决策前信息是否仍有效 补侦察后说一句结论
第三层 发现即时变化 动作空窗是否扫描地图异常 动作完成后短扫一次

每次信息都应形成“看见什么、意味着什么、下一步做什么”。无法确认时保留不确定性和验证动作，不把猜测包装成事实。

训练顺序

  1. 经常忘记侦察：先建立首侦触发器
  2. 首侦后仍机械执行：训练信息刷新
  3. 多线和绕后总是发现过晚：训练小地图短扫

一次只训练一层，优先处理最早丢失信息的位置。

本章边界

本章负责获取和解释信息。方向明确后能否及时行动，由局势响应、支援与风险控制处理；接敌后的具体控制由战斗控制与交换质量处理。

第一层：首侦按时完成

本层结论

在对手第一轮关键选择产生威胁前完成首侦，并把看到的信息转成一句明确结论。

在链条中的位置

首侦的价值不是“去过对面家”，而是在自己仍有调整空间时拿到信息。过晚的侦察即使看见了科技、兵力或扩张，也可能已经来不及改变生产和站位。

如何判断

首侦完成必须包含三个动作：

  1. 按预定时机派出侦察单位
  2. 看见能够区分对手主线的关键信息
  3. 用一句话说明下一步保持什么或改变什么

只完成移动、不形成结论，不算有效首侦。

怎么做

  1. 局前确定首侦触发器
  2. 确定首侦必须回答的一个问题
  3. 侦察后立即形成一句结论
  4. 执行一个保持或调整动作
  5. 局后检查信息是否在决策前到达

常见失败

  • 想把经济做顺以后再侦察，导致信息到得太晚
  • 侦察单位进入错误路线，没有覆盖关键区域
  • 看见建筑或兵量，但没有改变自己的计划
  • 团队局里重复侦察同一区域，却没人覆盖其他方向

达标标准

单局达标

  • 首侦没有因忘记或犹豫明显延后
  • 至少获得一条可用于判断的信息
  • 能说清“看到了什么，因此做了什么”

多局完成

连续三局中至少两局完成有效首侦，且没有因为侦察操作造成明显的开局主线断档。

本局训练卡：首侦三步闭环

使用条件

  • 经常忘记首侦
  • 首侦到达时已经无法调整
  • 看见信息后仍按原计划机械执行

本局只改什么

完成一次“按时出发、得到信息、执行动作”的首侦闭环。

触发时机

  • 局前预定的首侦节点到达

BGH 团队局中，应在出发前确认自己负责的侦察方向，避免和队友重复。

观察对象

  • 对手关键建筑、兵量、扩张或缺失信息
  • 自己是否仍有调整生产和站位的时间
  • 队友是否需要同步这条信息

判断规则

  • 看见明确主线：说出结论并决定保持或调整
  • 信息不足：明确缺什么，不假装已经确认
  • 侦察单位失去价值：及时退出，不持续占用注意力

常见错误

  • 出发过晚
  • 只完成移动，没有观察目标
  • 看到异常但没有动作
  • 团队内重复侦察同一路线

单局达标标准

  • 首侦按预定触发器出发
  • 获得至少一条有效信息
  • 信息后产生一个明确的保持或调整动作

多局完成标准

连续三局中至少两局达标，且首侦没有明显破坏自己的开局主线。

局后复盘

  1. 首侦什么时候出发
  2. 看到了什么有效信息
  3. 信息改变了哪个动作

地图适配：BGH

本层变化

首侦前先分配方向，避免多人重复确认同一区域。个人仍完成“出发、观察、行动”闭环，但关键结论需要同步给队友。

场景动作

  1. 开局前确认自己负责的方向
  2. 优先确认会改变团队第一轮行动的信息
  3. 用“哪一侧、什么变化、谁需调整”同步结论

失败信号

  • 多人重复侦察同一区域
  • 看见异常兵量、科技或空缺位置却没有同步
  • 只报告事实，没有说明对团队行动的影响

第二层：刷新信息并形成行动

本层结论

在旧信息失效前主动补侦察，并把新发现压缩成一个可执行结论。

在链条中的位置

首侦只能解释早期局面。对手的扩张、科技、兵种和路线会变化，只看一次就容易在中期继续按过期假设行动。

如何判断

每次补侦察前先提出两个问题：

  1. 哪条旧信息已经可能失效
  2. 哪个新答案会改变我的下一步

侦察后用一句话完成：

看到的事实 -> 对局势的含义 -> 下一步动作

怎么做

  1. 局前写下一个必须更新的信息
  2. 为它设置中期刷新节点
  3. 侦察时最多回答两个问题
  4. 立即给出一句行动结论
  5. 局后检查结论是否实际改变动作

常见失败

  • 早期看过一次后不再更新
  • 漫无目的进入敌方区域，没有预设问题
  • 看见关键变化但没有调整计划
  • 团队局中看到信息却没有同步

达标标准

单局达标

  • 首侦后至少完成一次有效信息刷新
  • 刷新后形成一条事实、含义和动作完整的结论

多局完成

连续三局中至少两局达到单局标准，且没有把早期信息当作整局事实。

本局训练卡：补侦察后说一句结论

使用条件

  • 首侦完成后长期不再获取信息
  • 看见对手变化却没有调整动作

本局只改什么

中期完成一次补侦察，并说出“事实、含义、动作”一句结论。

触发时机

  • 首轮信息已经过去一个阶段
  • 对手兵种、扩张或科技可能变化

观察对象

  • 一个会影响当前决策的问题
  • 对手的新建筑、兵种、扩张或移动
  • 自己和队友需要改变的动作

判断规则

  • 得到新事实：立即形成行动结论
  • 没有确认事实：保留不确定性，不下绝对结论
  • 侦察失败：选择替代方式或安全线

常见错误

  • 侦察前没有问题
  • 一次试图确认所有信息
  • 只报告事实，不说明下一步

单局达标标准

  • 至少完成一次有效信息刷新
  • 形成一条可执行结论

多局完成标准

连续三局中至少两局达标。

局后复盘

BGH 的信息刷新优先覆盖会改变中路、边路支援和团队兵种安排的变化。

场景动作

补侦察前，从以下问题中选择一个：

  • 中路是否可以进入
  • 哪一侧可能前压、绕后或空投

  • 哪名队友需要提前调整兵种或路线

信息不完整时说明不确定性，并指定由谁、在何时再次确认。

  • 只有一人看到变化，其他人仍按旧计划行动

第三层：小地图短扫

本层结论

把短扫小地图绑定到稳定操作节点，尽早发现异常移动、队友受压和主力脱节。

在链条中的位置

小地图是持续更新战场状态的低成本入口。训练目标不是长时间盯图，而是在注意力切换之间及时发现是否有新事件需要处理。

如何判断

短扫时只回答两个问题：

  1. 是否出现新的异常
  2. 这个异常是否需要立即切屏确认

确认异常后再分类为主攻、骚扰、绕后、队友受压或无关事件。

怎么做

  1. 选择“生产后、主力移动后、战后”中的一个触发器
  2. 每次触发只做一次短扫
  3. 发现异常才切到现场确认
  4. 局后记录一次最早可发现但错过的信号

常见失败

  • 只有听到告警后才看小地图
  • 每次看得过久，反而漏掉当前操作
  • 看见红点后立即全军回防，没有确认威胁
  • 多线时试图平均处理所有位置

达标标准

单局达标

  • 主要触发器出现时能稳定短扫
  • 至少一次异常经过确认后形成合适动作

多局完成

连续三局中至少两局达到单局标准，且没有因长时间盯图中断当前操作。

本局训练卡：动作完成后短扫一次

使用条件

  • 经常等告警响起才发现威胁
  • 切屏和生产时完全忽略小地图

本局只改什么

每次主力获得新移动命令后，短扫一次小地图。

触发时机

  • 主力获得新的移动命令
  • 基础动作稳定后可增加生产完成和战后触发器

观察对象

  • 新出现的敌方移动
  • 队友是否受压
  • 自己的主力是否脱节

判断规则

  • 没有异常：继续当前动作
  • 有异常但不明确：切屏确认
  • 明确威胁：进入对应响应主题

常见错误

  • 看小地图时间过长
  • 看到红点就无条件回防
  • 一次增加过多扫描触发器

单局达标标准

  • 主要触发器出现时完成短扫
  • 至少一次异常经过确认后形成动作

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 第一次漏掉的异常是什么
  2. 哪个触发器本可更早发现
  3. 看见异常后是否先确认事实

本层变化

小地图短扫优先发现边位告警、中路主力移动、绕后空投和队友脱节。看到异常后由最近或职责最合适的队员确认，不要求全队同时切屏。

中路视野

准备控制中路时确认：

  1. 是否看见主要入口
  2. 是否覆盖可能的侧翼
  3. 失去视野后由谁补充
  4. 新信息会让队伍继续、等待还是撤退

失败信号

  • 看到多个红点后直接平均分兵
  • 抢中前只有兵力，没有入口和侧翼视野
  • 全队同时切屏确认同一个异常

具体训练：常见信息判断情景

信息训练不是记住所有开局，而是在有限观察下区分事实、推断和未知，并为下一步安排一个可执行动作。

怎么组织对练

由陪练方预先选择一种情景，训练方不知道答案：

  1. 每轮只需要确认一个核心问题
  2. 观察后用“事实、含义、动作”给出结论
  3. 无法确认时必须说出未知项和下一次验证方式
  4. 双方交换角色，每种情景至少重复三轮

第一轮允许完整观察，后续再限制侦察单位、时间或视野范围。

预期建筑没有出现

  • 先确认侦察位置和时间是否足以支持“没有出现”
  • 将结论表述为“这里暂时没看到”，不直接断言具体隐藏路线
  • 检查其他可能位置、气矿和兵量，寻找第二条证据
  • 在确认前选择兼顾主要风险的生产或站位
  • 找到缺失建筑的原因后，再决定保持计划还是转入防守

对手提前扩张

  • 同时确认扩张时间、入口兵力和主基地生产，不只看到一个新基地
  • 判断自己应立即施压、扩大经济还是取得地图位置
  • 为行动设置时间窗口，避免“知道对方扩张”却继续原计划
  • 下一次刷新重点检查扩张是否转化为工人、生产或科技
  • 无法形成有效压力时，不持续投入零散单位证明侦察有价值

气矿或科技明显提前

  • 记录看见的建筑、时间和已知兵量
  • 列出最可能改变的威胁类型，但保留尚未确认的部分
  • 安排反隐、防空、侦察或单位结构中的一个最低成本动作
  • 在关键单位可能完成前设置一次信息刷新
  • 新信息否定威胁后，及时停止过度防守

对手主力从视野中消失

  • 先标记最后出现的位置、时间和移动方向
  • 检查最短进攻路线、侧翼、空投路径和可能的回家路线
  • 用小地图确认自己、队友和关键入口，而不是盲目追进战争迷雾
  • 为最危险路线安排视野或最小防守
  • 主力重新出现后，立即更新旧判断

兵量与已知生产不一致

  • 先检查自己是否漏看生产建筑、基地或单位移动
  • 将异常分为隐藏生产、资源转科技、扩张或单位在其他路线
  • 选择一项能够区分这些可能性的补侦察
  • 在答案出现前，不用单一猜测要求全队完全转型
  • 找到原因后说明哪个旧判断失效

多线同时出现红点

  • 先区分主力、骚扰、绕后和无关单位
  • 只切屏确认会改变当前行动的异常
  • 标记主威胁、次威胁和可延后事件
  • 将确认结果交给响应章节处理，不在信息阶段直接平均分兵
  • 复盘第一次能够发现主威胁的信号

第四部分 操作组织与执行效率

操作组织与执行效率

有效操作不是按键越多越好，而是能快速调用需要的单位、带着目的切换画面，并在战斗与生产之间保持必要循环。

本章要解决的问题

玩家的注意力和操作次数有限。寻找单位、无目的切屏和一次处理过多事情，会挤占真正需要执行的动作。本章回答：

如何让有限操作稳定服务于当前任务？

答案是建立三层执行结构：

用固定编队快速调用
  -> 每次切屏只完成一个目的
  -> 在移动与战后恢复生产循环

三层判断模型

顺序 需要保证的事情 判断问题 本局动作
第一层 调用稳定 是否能立即选中主力、生产和功能单位 三组固定职责
第二层 切换有效 每次切屏前是否知道要完成什么 切过去先做一件事
第三层 循环不断 战斗与移动是否让生产长期中断 移动补一轮，战后接一轮

前一层不稳定时，增加操作速度只会制造更多误选和无效切换。

训练顺序

  1. 经常找不到主力或续兵：先固定编队职责
  2. 切屏很多但有效动作少：训练目的驱动的切屏
  3. 一打架就断工断兵：训练战斗与生产循环

每局只改变一个操作习惯，并记录第一次失败的触发场景。

本章边界

本章负责动作如何稳定执行，不负责判断采用哪种战略，也不使用操作速度代替执行质量。

第一层：稳定编队调用

本层结论

固定主力、生产和关键功能单位的编队职责，在需要行动时直接调用，而不是临时找单位。

在链条中的位置

编队本身不直接赢得比赛，但它决定玩家能否稳定执行生产、侦察、支援和战斗决策。编队频繁变化会把注意力浪费在重新框选和确认单位上。

如何判断

基础阶段只固定三类职责：

  1. 主力编队：承担移动、集合和主要接敌
  2. 生产编队：承担持续生产
  3. 功能编队：承担侦察、运输或关键施法

每个编号只承担一个稳定职责。新增单位时补入已有职责，不临时整体换号。

怎么做

  1. 局前写下三个固定职责
  2. 开局建立主力和生产编队
  3. 每轮新兵完成后补入主力
  4. 每次出门前用热键调用并确认主力
  5. 局后只记录找兵、错组和漏编次数

常见失败

  • 同一个编号在不同时间代表不同职责
  • 主力出门后仍依赖鼠标回地图寻找
  • 新生产单位长期没有加入主力
  • 为覆盖所有单位一次建立过多编队
  • 误编后立即重做整套编号，进一步打乱节奏

达标标准

单局达标

  • 没有因为找兵或错组错过关键出门、支援或接敌
  • 三个核心编队职责从建立后保持稳定

多局完成

连续三局均能保持核心职责，且至少两局没有出现明显找兵或整体重编。

三族基础编队示例

编队编号没有唯一正确答案。示例只提供稳定职责骨架，玩家可以调整具体号码，但同一局内不要反复改变职责。

先完成稳定编队调用，再使用本页增加种族细节。

通用起步骨架

职责 建议用途
主力组 当前主要作战单位和移动主体
第二作战组 远程、侧翼或需要单独移动的单位
功能组 侦察、运输、法术或关键支援单位
基地组 工人生产和基地状态
主生产组 当前主要生产设施

新手先固定前三类职责。只有在找兵和漏编明显减少后，再增加更多作战或建筑组。

Protoss 示例

  • 主力组：Zealot 或当前前排
  • 第二作战组：Dragoon 或远程主力
  • 功能组：Shuttle、Observer、Corsair 或 High Templar
  • 基地组：Nexus
  • 主生产组：Gateway

重点是把前排、远程和功能单位分开，避免为了施法或运输拖动整个主力。

Terran 示例

  • 主力组：Marine、Vulture 或当前机动主体
  • 第二作战组：Tank 或重火力
  • 功能组：Science Vessel、Dropship 或侦察单位
  • 基地组：Command Center
  • 主生产组：Barracks 或 Factory

中后期单位职责增多时，优先增加作战组，不要让同一个编号同时承担 Tank、Vulture 和功能单位。

Zerg 示例

  • 主力组：第一支 Ling、Hydra 或地面主力
  • 第二作战组：第二方向部队
  • 功能组：Mutalisk、Lurker、Defiler 或 Scourge
  • 基地与生产组：Hatchery、Lair 和 Hive

Zerg 的基地同时承担生产职责，可以为 Hatchery 保留更多稳定编号，但不要求所有玩家采用相同数量。

什么时候调整

可以调整：

  • 某组只剩少量残兵
  • 兵种结构发生明显变化
  • 前期骨架无法承载中期职责

不要调整：

  • 正在激烈交战
  • 只是一次误编就想重做全部编号
  • 真正问题是漏生产或漏看图

调整时只修正受影响的职责，并把新兵补入已有主力，不在高压时整体换号。

本局训练卡：三组固定职责

使用条件

  • 经常找不到主力或新生产单位
  • 编队编号在一局中反复改变
  • 需要支援或接敌时仍依赖鼠标重新框选

本局只改什么

固定三个职责：主力、生产、功能单位。具体编号自定，但本局不更换职责。

触发时机

  • 新单位生产完成
  • 主力准备出门
  • 一波交战结束

观察对象

  • 主力编队是否包含当前主要作战单位
  • 生产编队是否仍能直接调用
  • 功能单位是否有明确归属

判断规则

  • 新兵属于主力：补入主力编队
  • 单位承担独立功能：放入功能编队
  • 误编发生：只修正受影响编队，不重做全部编号

常见错误

  • 一个编号承担多个不断变化的职责
  • 为追求完整一次建立过多编队
  • 战后忘记把续兵补入主力
  • 误编后反复重置所有编队

单局达标标准

  • 三个核心职责保持稳定
  • 没有因找兵或错组错过关键行动

多局完成标准

连续三局均保持核心职责，且至少两局没有明显找兵或整体重编。

局后复盘

  1. 哪个职责第一次失效
  2. 新兵是否及时补入主力
  3. 下一局是否需要减少而不是增加编队

本层变化

功能编队优先承载侦察、运输或支援单位。团队口令出现时，应能直接调用对应单位，不临时回地图寻找。

场景动作

  • 集合前把新兵补入主力
  • 队友请求侦察、运输或支援时直接调用功能编队
  • 主力与续兵从不同路线会合时分别控制，不混成一个临时职责

失败信号

  • 主力和功能单位无法分别移动
  • 收到队友口令后临时寻找单位
  • 续兵没有补入主力，接战时分批到场

第二层：有效切屏

本层结论

每次切到主力、基地、生产区或侦察点时立即完成一个明确动作，减少无目的来回切换。

在链条中的位置

切屏本身不会推进局面。有效切屏应快速到达目标位置、完成动作并离开，否则只会占用注意力并增加忘记原任务的风险。

如何判断

切屏前先说出目的：

  • 主力：移动、接敌、后撤或集合
  • 基地：补工或检查补给
  • 生产：补兵或关键建筑
  • 侦察：回答一个会改变决策的问题

切到目标后先完成这个动作，再决定是否停留。

怎么做

  1. 固定主力、基地和生产入口
  2. 每次切屏前说出一个目的
  3. 完成一个动作后立即离开
  4. 局后记录第一次无效切屏

常见失败

  • 紧张时频繁切屏但没有下指令
  • 切到基地后一次处理太多事务
  • 侦察画面停留过久，漏掉前线和生产

局势响应、支援与风险控制

正确响应不是看见告警就拉兵，而是先判断是否值得支援，再明确到场方式，并在收益消失时及时止损。

本章要解决的问题

威胁出现后，可行动时间通常很短。盲目支援会放弃自己的位置，犹豫不决又会错过窗口。本章回答：

如何在有限信息和时间下，完成可执行、可停止的响应？

答案是按顺序处理三层：

判断是否支援
  -> 明确结论并及时到场
  -> 条件恶化时收手撤退

三层判断模型

顺序 需要保证的事情 判断问题 本局动作
第一层 选择响应 赶得到、救得下、离得开、值得吗 支援前问四个问题
第二层 启动行动 路线和到场结论是否明确 告警后看算说动
第三层 控制损失 原目标是否仍值得投入 阵型拉长就停一下

错误方向执行得再快仍然是错误；方向正确但没有明确启动和退出条件，同样不能形成有效响应。

训练顺序

  1. 告警后经常盲目拉兵：先训练支援判断
  2. 判断正确但总是到场过晚：训练行动启动
  3. 到场后持续追深或分批投入：训练止损撤退

多线出现时先确定主战场、次战场和可交换点，不平均分配兵力。

本章边界

本章负责决策后的行动、支援与止损。对手意图识别由信息获取与判断处理；接敌后的阵型和集火由战斗控制与交换质量处理。

第一层：判断是否支援

本层结论

队友受压时根据距离、到场时间、兵力和代价判断立即支援、稍后支援还是明确放弃。

在链条中的位置

该救不救会让队伍长期少一人，不该硬救却连续投入会把局部损失扩大成全队崩盘。支援首先是优先级判断，其次才是移动速度。

如何判断

收到告警后依次判断：

  1. 到得了吗：路线和预计到场时间
  2. 到了能打吗：兵种、人数和阵型
  3. 去了会丢什么：自己的基地、主力或关键位置
  4. 不去怎么止损：撤退、换点、防守或反击

结论只保留三种：立即到、稍后到、无法到并执行止损。

怎么做

  1. 约定一个告警词
  2. 第一次告警后完成四项判断
  3. 给出三种结论之一
  4. 按结论执行，不在路上反复摇摆
  5. 局后复盘结论是否减少总损失

常见失败

  • 只凭情绪决定救不救
  • 明知到场太晚仍分批投入
  • 为救次要位置放弃更重要的基地或主力
  • 决定不救但没有告诉队友如何止损

达标标准

单局达标

  • 至少一次告警后给出明确支援优先级
  • 没有在已无救援价值时继续分批投入

多局完成

连续三局中至少两局达到单局标准，并能区分迟到和不该支援。

本局训练卡：支援前问四个问题

使用条件

  • 队友告警后经常盲目拉兵
  • 明知赶不到仍持续分批投入

观察对象

  • 双方可用兵力与阵型
  • 自己离开后的风险

  • 需要集合或补齐兵力：稍后到并说明条件
  • 已无救援价值：明确无法到并执行止损

常见错误

  • 不看现场直接出发
  • 在路上反复改变结论
  • 说不能到，却没有任何替代动作

单局达标标准

  • 至少一次形成明确支援结论
  • 没有在结论无效后继续分批送入

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 这次支援结论是什么
  2. 到场后是否真的能打
  3. 不支援时采取了什么止损动作

本层变化

判断支援价值时加入出生位距离、中路是否可通行，以及自己离开后的基地风险。多线出现时先划分主战场、次战场和可交换点。

场景动作

  1. 先处理会立即影响主力或关键基地的主战场
  2. 为次战场分配最小必要反应
  3. 明确暂时放弃可交换点
  4. 无法救援时选择撤退、换点、防守或反击

失败信号

  • 同时响应每条线并平均分兵
  • 明知无法到场仍持续分批支援
  • 决定换家但没有收益目标和退出条件

第二层：支援及时到场

本层结论

队友受压后立即确认威胁、路线和到场时间，避免犹豫过久或分批送入战场。

在链条中的位置

团队局中的支援价值取决于到场时点。方向正确但晚到，仍可能让队友先损失兵力、建筑或位置；没有确认路线就直接冲，也可能把一次救援变成连续送兵。

如何判断

出现队友告警或异常交战时，按顺序完成：

  1. 看：切到相关位置确认真实威胁
  2. 算：判断自己的路线和预计到场时间
  3. 说：明确“立即到、稍后到或无法到”
  4. 动：按结论统一移动，不让部队分批进入

本主题先训练快速形成可执行结论，不追求每次都做出完美战略判断。

怎么做

  1. 约定一个清晰告警词
  2. 告警出现后先切现场
  3. 在短时间内给出到场判断
  4. 用一个集合点组织主力和续兵
  5. 局后记录第一次支援是否改变局面

常见失败

  • 听到告警后继续完成自己的生产或骚扰动作
  • 没看现场就直接拉兵，路线和兵力都不合适
  • 主力、续兵和队友分批到场
  • 明知无法及时到场，却没有明确告知队友止损

达标标准

单局达标

  • 至少一次告警后完成“看、算、说、动”闭环
  • 没有因犹豫或路线错误造成明显迟到
  • 无法到场时给出明确反馈并避免继续扩大损失

多局完成

连续三局中至少两局完成一次有效支援闭环，并能区分“到场慢”和“本来就不该支援”。

本局训练卡：告警后看算说动

使用条件

  • 队友受压时经常反应过晚
  • 支援方向正确但到场时局面已经结束
  • 主力和续兵容易分批进入战场

本局只改什么

  • 团队约定位置失去视野或控制

  • 威胁位置和兵力
  • 自己主力当前位置
  • 可用路线和预计到场时间
  • 队友是否能坚持到自己到场

判断规则

  • 能及时到场：明确回复并统一移动
  • 需要短暂准备：说明延迟和集合点
  • 无法有效到场：明确告知队友止损，不分批送入

常见错误

  • 没看现场就移动
  • 犹豫到局面结束才出发
  • 不沟通自己的到场判断
  • 主力、续兵和队友分批接敌

单局达标标准

  • 至少一次告警后完成四步闭环
  • 没有因犹豫、路线错误或分批移动造成明显迟到

多局完成标准

连续三局中至少两局完成有效支援闭环，并能指出一次不应支援的局面。

局后复盘

  1. 第一次告警后多久看现场
  2. 到场判断是否准确
  3. 队友是否知道自己的结论
  4. 本局问题是判断错还是执行慢

固定车队应约定一个告警词和一个集合口径。结论形成后，主力、续兵和队友按同一到场方案行动。

场景动作

  • 有人抢中、有人发育，但没有明确结论

第三层：及时收手与撤退

本层结论

优势追击开始拉长阵型或劣势交换继续扩大时，及时停止投入并沿安全路线撤退。

在链条中的位置

撤退是主动控制损失，不是部队已经崩溃后的被动逃跑。及时收手能保留主力、续兵和下一轮地图行动能力。

如何判断

准备继续追击或交战时检查：

  1. 队友和续兵是否还能接上
  2. 阵型是否开始拉长
  3. 对手是否接近增援、阵地或有利地形
  4. 当前收益是否值得新增风险

任意两项明显不利时，停止追击，选择撤退路线并重新集合。

怎么做

  1. 局前约定一个收手信号
  2. 对手后撤时执行四项检查
  3. 决定继续、停下或撤退
  4. 撤退后先重组阵型，再决定下一步
  5. 局后复盘一次最晚收手点

常见失败

  • 小优后持续追深，把优势变成反亏
  • 已经打亏仍不断补入新单位
  • 撤退时各组走不同方向
  • 只下后撤命令，没有选择安全路线

达标标准

单局达标

  • 至少一次在阵型恶化前停止追击
  • 撤退后没有让续兵继续分批送入

多局完成

连续三局中至少两局达到单局标准，并能说清一次继续追击或及时撤退的依据。

本局训练卡：阵型拉长就停一下

使用条件

  • 优势时经常追得过深
  • 劣势时持续把续兵送进已经失败的战斗

对手后撤且己方阵型开始拉长时，先停止追击并检查队友和续兵。

触发时机

  • 对手主力后撤
  • 己方前后排或队友距离明显扩大

观察对象

  • 队友和续兵距离
  • 对手增援与有利地形
  • 当前已获得的收益
  • 可用撤退路线

判断规则

  • 阵型完整且收益明确：有限继续
  • 阵型拉长或对手接近增援：停止追击
  • 已经打亏：统一撤退并拦住续兵

常见错误

  • 把任何后撤都当成必须逃跑
  • 停止主力但忘记续兵
  • 撤退时仍频繁回头攻击

单局达标标准

  • 至少一次触发时先停下检查
  • 没有因追深或续兵分批造成明显反亏

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 阵型从什么时候开始拉长
  2. 最晚可以安全收手的节点是什么
  3. 撤退时续兵是否同步停止

本层变化

追出中路或深入对手半场前检查队友和续兵。决定撤退时统一回收路线，避免主力撤走而后续兵继续从原路线进入。

场景动作

  1. 约定统一收手口令
  2. 指定主力回收路线和重新集合点
  3. 拦住生产点到前线之间的续兵
  4. 回收后重新判断防守、换点或再次进入

失败信号

  • 主力撤退后续兵继续送入
  • 队员沿不同方向回收并被逐个截断
  • 已失去收益仍持续追深

具体训练：常见局势响应

响应训练不是要求每次都支援，而是让玩家在固定情景中形成明确结论、统一行动和停止条件。

怎么组织对练

由陪练方或队友在约定时间触发一种局势：

  1. 训练方先完成支援四问
  2. 结论只使用“立即到、稍后到、无法到”
  3. 行动前说明集合点、路线或止损方式
  4. 条件变化后再次判断继续、换点或撤退

每种情景重复三轮，第一轮固定路线，后续再改变距离、视野或兵力。

邻近队友遭遇早期压力

  • 先看现场兵力和队友可坚持时间
  • 计算自己主力与续兵能否同时到场
  • 能救时给出集合点和到场结论
  • 赶不到时要求队友撤退，并选择防守下一位置或反击
  • 不让少量单位先后进入已经失败的战场

中路即将接敌

  • 检查兵力、视野、队友和退路
  • 缺少一项且能快速补齐时明确等待条件
  • 缺少两项以上时放弃本轮硬抢
  • 决定进入后统一前排、后排和支援的到场方向
  • 占住中路后说明要转化的视野、路线或资源收益

主战场与骚扰同时发生

  • 判断哪一处会立即影响主力或关键基地
  • 主战场保留形成有效交换所需的兵力
  • 为骚扰分配最小必要反应，不平均分兵
  • 暂时放弃的位置必须说明可接受损失
  • 主威胁消失后再重新分配兵力

已经无法及时救援

  • 明确说出“无法到”，停止继续派出零散援军
  • 要求受压方选择撤退路线和可保留资产
  • 自己选择换点、防守、反击或扩大经济中的一个动作
  • 重新判断对手主力下一步可能到达的位置
  • 复盘最晚仍有救援价值的时间点

优势追击开始拉长

  • 检查队友、续兵、对手增援和当前收益
  • 阵型开始断开时先停止最前方单位
  • 收益明确且退路安全时有限继续
  • 对手接近阵地或己方后排脱节时统一撤退
  • 拦住仍沿原路线进入的续兵

换家与对攻

  • 确认当前已经难以及时回防
  • 说明准备破坏的关键资源、生产或科技目标
  • 保留后续生产、撤退或重新集合条件
  • 队友必须知道共同目标和停止条件
  • 无法形成有效破坏时，不把继续前进包装成换家决策

第六部分 战斗控制与交换质量

战斗控制与交换质量

好的战斗不是更快地冲上去，而是先建立可打的阵型，再把第一轮火力集中到可触达的关键目标。

本章要解决的问题

双方兵力接触后，几秒内的站位和目标选择会决定交换结果。兵力优势也可能被拥堵、脱节和分散火力浪费。本章回答：

如何在接敌前形成有效展开，并让第一轮攻击产生确定收益？

答案是先后完成两层：

确认接敌条件与阵型
  -> 第一轮集中攻击一个可触达目标

两层判断模型

顺序 需要保证的事情 判断问题 本局动作
第一层 接敌条件成立 人数、地形和阵型是否允许开打 开打前看人地阵
第二层 第一轮火力有效 首要目标是否值得且可触达 第一轮只选一个目标

阵型没有展开时，不为点杀高价值单位强行追深；目标不可触达时，应重新选择，而不是让全军拥堵。

训练顺序

  1. 经常队友未到或阵型混乱就开战：先练接敌与展开
  2. 阵型稳定但火力自然分散：再练第一拍集中火力
  3. 两层稳定后，再增加技能、拉扯、包夹和多目标控制

本章边界

本章负责兵力投入战斗后的接敌和火力组织。开战前是否获得足够信息由信息获取与判断处理；是否支援和何时止损由局势响应、支援与风险控制处理。

第一层：接敌与战前展开

本层结论

开战前确认人数、地形和阵型，选择主动接敌、等待队友或后撤重组。

在链条中的位置

许多交换在第一轮输出前已经由接敌条件决定。人数未齐、地形拥挤或后排暴露时强行开战，会让后续集火和操作失去基础。

如何判断

接敌前只检查三项：

  1. 人齐了吗：队友、主力和续兵是否接上
  2. 地形好吗：是否被狭口、坡口或包夹限制
  3. 阵型开了吗：前排能承伤，后排能输出

三项中有两项不满足时，优先等待、换位或后撤重组。

怎么做

  1. 每次主要接敌前说出三项检查
  2. 选择打、等或退
  3. 需要开打时先展开前后排
  4. 从常用兵种对抗训练选择一组固定条件对练
  5. 局后只复盘接敌前一刻

常见失败

  • 自己先看到敌人就立即开打
  • 狭口里前后排挤成一团
  • 后排先暴露，前排还未就位
  • 队友未到却按完整兵力判断胜负

达标标准

单局达标

  • 至少两次主要接敌前完成三项检查
  • 没有在明显人数不足或阵型未开时主动硬打

多局完成

连续三局中至少两局达到单局标准，并能说清一次选择等待或后撤的原因。

具体对抗训练：常用兵种组合

兵种对抗训练不是背谁克制谁，而是在固定条件下反复练习展开、输出、拉扯和脱离。升级、地形、视野、支援单位和操作空间都会改变结果。

怎么组织对练

  1. 使用自定义地图或约定对练固定双方兵力。
  2. 第一轮使用开阔地形、相同攻防升级且不加入援军。
  3. 双方交换阵营，各重复三次。
  4. 每次只记录阵型是否展开、第一轮输出是否有效、何时应该脱离。
  • 基础对抗稳定后，每轮只增加一个变量：狭口、坡口、升级或支援单位。
  • 固定数量只用于建立可重复起点，不代表实战中的绝对胜负。
  • 复盘优先看保留兵力和位置收益，不只看最后哪一方全灭。

六龙骑对十二枪兵

基础条件
  • 第一轮不加入兴奋剂和医疗兵；加入后视为新的训练条件。
  • 使用开阔地形和相同攻防升级。
训练重点
  • 展开：让龙骑形成浅弧或横线，保证多数单位能同时开火。
  • 射程与拉扯：利用射程完成第一轮输出，在攻击间隔中后拉，不站在原地换血。
  • 可触达集火：优先攻击前排可触达枪兵，击杀后重新选目标，避免炮火过量落在同一残血单位上。
  • 避免拥堵：避免在狭口中互相拥堵，也不让枪兵贴近侧面或包住后撤路线。
脱离条件
  • 枪兵完成贴身。
  • 龙骑阵型被压缩。
  • 兴奋剂与医疗兵加入且当前条件未重新评估。

狂热者对秃鹫

基础条件
  • 第一轮不放置蜘蛛雷。
  • 使用有转角但不存在封闭死角的路线。
训练重点
  • 缩短距离：利用转角、狭窄路线或双向包夹缩短秃鹫的拉扯空间。
  • 分路接近：多名狂热者分开接近，不沿同一条直线追赶。
  • 蜘蛛雷检查：接近前确认蜘蛛雷位置，不让第一名狂热者把地雷引向整队。
  • 贴身集火：形成贴身后集中处理同一侧目标，避免每名狂热者追不同秃鹫。
脱离条件
  • 无法缩短距离。
  • 包夹路线消失。
  • 蜘蛛雷区域不明。
下一轮变量
  • 蜘蛛雷
  • 开阔地形
  • 狭窄路线
  • 速度升级
  • 双向包夹

龙骑对攻城坦克

基础条件
  • 明确坦克是否处于攻城模式。
  • 第一轮不加入雷车、雷区或其他前排掩护。
训练重点
  • 射程确认：先确认坦克是否架起以及射程边界，不让龙骑单列进入阵地。
  • 横向展开：在空间允许时横向展开，从两个方向压缩坦克的安全位置。
  • 处理前排：第一轮优先处理暴露且可触达的前排坦克，不为后排目标穿过火力区。
  • 范围伤害间距：攻击后重新拉开间距，避免龙骑重叠承受范围伤害。
脱离条件
  • 坦克拥有完整前排掩护。
  • 己方只能穿过狭口。
  • 缺少确认阵地所需的视野。
下一轮变量
  • 攻城模式
  • 高地视野
  • 狭口
  • 前排雷车
  • 双向包夹

枪兵与医疗兵对狂热者

  • 枪兵与医疗兵已经编入可独立调用的队伍。
  • 第一轮使用开阔地形。
训练重点
  • 火力线：接敌前展开枪兵火力线，将医疗兵放在后方而不是最前排。
  • 前排集火：狂热者即将接触时集中攻击最前方可触达目标，不跨过前排点深处单位。
  • 短距离后拉：短距离后拉以保持输出空间，但不要连续后撤到火力线自行断开。
  • 兴奋剂时机：兴奋剂用于明确的接敌窗口，不在没有目标时提前消耗生命。
脱离条件
  • 狂热者完成多方向包夹。
  • 医疗兵与枪兵脱节。
  • 枪兵被压进角落。
下一轮变量
  • 兴奋剂
  • 医疗兵数量

本局训练卡：开打前看人地阵

使用条件

  • 经常队友未到就先接敌
  • 前后排拥挤或后排先暴露

本局只改什么

每次主要接敌前检查人数、地形和阵型，再决定打、等或退。

触发时机

  • 主力即将进入对手攻击范围
  • 双方在路口或中心区域准备接触

观察对象

  • 队友、主力和续兵位置
  • 狭口、坡口和包夹路线
  • 前排与后排是否展开

判断规则

  • 三项基本满足：准备接敌
  • 两项不满足：等待、换位或后撤
  • 对手暴露明显机会：说明理由后主动先手

常见错误

  • 检查完仍按原惯性开打
  • 只看己方人数，不看地形
  • 为展开阵型拖得过久，错失明确机会

单局达标标准

  • 至少两次主要接敌前完成三项检查
  • 没有明显脱节或拥挤时强行开战

多局完成标准

连续三局中至少两局达标。

局后复盘

  1. 最关键一波开战前哪项未满足
  2. 应该打、等还是退
  3. 阵型问题发生在前排还是后排

本层变化

中路、路口和多方向到场会放大阵型问题。接敌前除人数、地形和阵型外，还要确认前排、后排与支援能否同时到场。

抢中前检查

  1. 兵力：主要作战单位是否到位
  2. 视野：是否看见主要入口和可能的侧翼
  3. 队友：前排、后排和支援是否能同时接敌
  4. 退路：无法站稳时从哪里回收

前三项明显不足时，不让单人先进入试探性硬打。

失败信号

  • 一名玩家先到中路并独自接敌
  • 前排、后排从不同方向分批进入
  • 只占住中路，却没有获得资源、视野或路线收益

第二层：第一拍集中火力

本层结论

接敌后的第一轮输出集中到同一个高价值且可触达的目标，避免火力自然分散。

在链条中的位置

第一拍输出会改变后续兵力数量和阵型。尽快击杀一个有效目标，通常比同时打伤多个目标更容易形成局部优势；但为了集火不可让大量单位停火、拥堵或深入危险位置。

如何判断

接敌前只判断三件事：

  1. 哪个目标价值高
  2. 哪个目标当前能够被大部分火力触达
  3. 为了攻击它是否会破坏阵型

优先选择“高价值且可触达”的目标。无法安全集火时，保持输出比强行点杀更重要。

怎么做

  1. 接敌前选定一个首要目标类型
  2. 第一轮只下达一次明确集火命令
  3. 观察多数单位是否能持续输出
  4. 目标脱离射程或阵型恶化时停止追深
  5. 局后只复盘第一轮目标和火力分布

常见失败

  • 看到高价值单位就让全军深入追击
  • 频繁切换目标，第一轮没有击杀任何单位
  • 只操作少量前排，后排单位没有输出
  • 为了集火让近战单位堵在同一路口
  • 不看队友攻击方向，各自选择不同目标

达标标准

单局达标

  • 至少两次主要接敌前明确首要目标
  • 第一轮没有出现明显火力分散
  • 没有为完成集火造成明显阵型崩坏

多局完成

连续三局中至少两局达到单局标准，并能说清一次放弃集火、改为保持阵型的原因。

本局训练卡：第一轮只选一个目标

使用条件

  • 接敌后火力自然分散
  • 频繁切换目标，没有形成击杀
  • 为了点杀高价值单位经常破坏阵型

本局只改什么

每次主要接敌前选一个高价值且可触达的首要目标，第一轮只下达一次明确集火命令。

触发时机

  • 双方主力即将进入射程
  • 队友明确发出集火目标

观察对象

  • 目标价值
  • 多数单位是否能触达
  • 集火动作是否会破坏阵型
  • 目标脱离后是否仍值得追击

判断规则

  • 高价值且可触达：执行集火
  • 高价值但不可触达：保持有效输出，不强行深入
  • 目标脱离且阵型拉长：停止追击，重新组织

常见错误

  • 只看价值，不看可触达性
  • 第一轮频繁换目标
  • 大量单位为追一个目标停止输出
  • 把集火训练成无条件追击

单局达标标准

  • 至少两次主要接敌前明确首要目标
  • 第一轮没有明显火力分散
  • 没有因集火造成明显阵型崩坏

多局完成标准

连续三局中至少两局达标，并能说清一次放弃集火的原因。

局后复盘

  1. 第一轮选择了什么目标
  2. 多数单位是否能够输出
  3. 是否因为集火破坏阵型
  4. 下一局要改目标选择还是收手时机

本层变化

团队接敌前由最先获得视野或最适合判断的人说明首要目标类型。每名玩家仍需确认目标是否可触达，不能为了服从口令破坏阵型。

场景动作

  • 主力即将接触时统一第一目标
  • 包夹或侧翼到位后再确认可触达性
  • 目标退出射程时停止追深并重新组织
  • 面对完整阵地时先控制资源、视野和路线，再等待破阵窗口

失败信号

  • 队员分别攻击不同目标
  • 目标不可触达时仍全军追深
  • 在完整防守阵地前持续投入
  • 第一目标消失后没有重新组织火力

综合决策与训练计划

找到最早断点

├─ 否：训练接敌检查与战前展开
└─ 是：第一轮火力是否集中到可触达目标？
   ├─ 否：训练第一拍集中火力
   └─ 是：本章训练暂时达标

阵型未建立时先等待、换位或后撤。高价值目标不可触达时，保持有效输出比强行点杀更重要。

三局训练计划

  1. 第一局每次主要接敌前检查人数、地形和阵型。
  2. 第二局在条件成立后，为第一轮选择一个高价值且可触达的目标。
  3. 第三局同时执行两层，并记录一次主动放弃接敌或集火的正确决定。

进行具体兵种对抗时，三局保持相同兵种、数量、升级和基础地形；完成后每轮只改变一个条件。

本章完成标准

  • 连续三局中至少两局在主要接敌前完成检查
  • 没有在队友未到或阵型拥堵时强行开战
  • 第一轮火力集中，没有频繁更换目标
  • 目标不可触达时没有破坏阵型追深
  • 能说清一次选择打、等、退或换目标的依据

进入条件

  • 经常卡人口
  • 首侦没有固定时机

  • 接敌后火力明显分散

  1. 稳定编队调用
  2. 有效切屏
  3. 战斗与生产循环
  4. 持续补充工人
  5. 补给节奏
  6. 保持主生产线运转

  2. 刷新信息并形成行动

  2. 只带对应基础训练卡进入单局

  • 因种族或地图无法执行：调整具体动作，不改变主题目标

完成条件

BGH 地图、点位与路线

本页用于局前识别位置风险和团队路线。它不替代具体训练主题，也不把出生位固定成永久角色。

局前位置检查

每名玩家开局前回答：

  1. 我离哪一侧对手最近
  2. 哪名队友最可能先承受压力
  3. 我的最快支援路线是什么
  4. 默认集合点和失守后的回收点在哪里

无法快速回答时，队伍应减少复杂战术，优先保证首侦和支援路线清楚。

位置类型

边位或近敌位

  • 更早承担外侧和近点压力
  • 优先确认防守入口、求援信号和撤退路线
  • 开局模板应保留更早自保和支援能力

内位或相对安全位

  • 更适合承担补位、转线或中期输出
  • 不能因为安全就放弃首侦和团队到场
  • 贪经济或科技前必须确认谁覆盖第一波

中路连接位

  • 更容易参与第一轮集合和路线控制
  • 需要持续关注两侧队友是否脱节
  • 中路价值来自视野和转移效率，不等于必须无条件抢占

资源点检查

准备扩张或控制中矿前检查：

  1. 新资源点是否处于可支援范围
  2. 是否存在高地、架点、空投或绕后风险
  3. 队伍能否维持通往该点的路线
  4. 占领后准备转成工人、兵力、科技还是下一处地图控制

只占住资源点但无法防守、采集或转化，不算完成扩张目标。

默认路线

固定车队至少约定三条路线：

  • 默认集合线：没有特殊情况时的第一集合方向
  • 默认补位线：边位或队友受压时的最快支援方向
  • 失守回收线：中路或前线无法维持时的撤退和重组方向

路线不是固定命令。侦察发现埋伏、封锁或空投威胁后，应切换到更安全的路径并同步队友。

复盘问题

  • 这局位置判断是否改变了开局选择
  • 第一次支援是否走了正确路线
  • 哪个资源点的风险在扩张前被忽略
  • 丢失前线后是否有统一回收位置

涉及具体悬崖、矿线和架点的位置，需要结合实际地图画面验证，不凭文字记忆下绝对结论。

BGH 临时团队角色

角色用于说明本局谁先承担哪项职责，不是对玩家或种族的永久标签。出生位、队友组合、侦察信息和战局变化都可以改变角色。

先手施压

主要职责：

  • 前期制造压力并争取主动
  • 迫使对手留兵或暴露防守
  • 为队友争取经济和科技时间

完成标准不是必须击杀对手，而是让压力产生可观察收益。

前排抗压

主要职责：

  • 稳住边线和第一轮正面
  • 为远程与科技单位提供输出空间
  • 受压时尽早报清位置、兵种和需要

抗压不是被动挨打。无法继续维持时，应及时后撤并请求明确支援。

远程支援

主要职责：

  • 补充后排火力和功能单位
  • 根据队友位置选择集合与到场路线
  • 避免脱离前排独自接敌

判断重点是到场、站位和目标，而不只是兵力数量。

科技与中期接管

主要职责：

  • 把队友争取的时间转成关键科技或中期兵力
  • 明确成型窗口和第一项团队用途
  • 前线危险时停止贪科技并补充必要防守

科技位必须说清谁在前期保护自己，以及何时开始为队伍提供价值。

局前分工

固定车队在一分钟内回答：

  1. 谁负责最早施压
  2. 谁先扛第一波
  3. 谁提供远程或机动支援
  4. 谁准备中期接管
  5. 哪个信号出现时需要交换角色

同一玩家可以承担多个相邻职责，但不能让关键职责无人承担。

角色切换

出现以下情况时重新确认：

  • 出生位与预期不符
  • 侦察发现对手开局改变
  • 前排损失过大
  • 科技或经济路线被迫中断
  • 某名队友已经提前形成关键兵力

切换后只需要说明新的主要职责和第一项动作，不重新设计整套团队计划。
